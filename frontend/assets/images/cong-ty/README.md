# Ảnh công ty cho trang Tầm nhìn & Sứ mệnh

Chép ảnh vào thư mục này **đúng tên file** bên dưới (đuôi `.jpg`, `.webp` hoặc `.png`).
Trang `tam-nhin-su-menh.html` tự nhận ảnh; chưa có ảnh thì hiện khung chờ có ghi tên file cần chèn.

| Tên file | Vị trí trên trang | Kích thước gợi ý |
|---|---|---|
| `hero.jpg` | Ảnh lớn đầu trang (trụ sở / toàn cảnh công ty) | 1200 × 1500 px (dọc) |
| `tam-nhin.jpg` | Mục Tầm nhìn – ảnh công trình / dự án tiêu biểu | 1200 × 1500 px (dọc) |
| `doi-ngu.jpg` | Mục Tầm nhìn – ảnh nhỏ đội ngũ kỹ thuật | 800 × 800 px |
| `gia-tri.jpg` | Mục Giá trị cốt lõi – ảnh hoạt động / văn hóa công ty | 1600 × 1000 px (ngang) |
| `anh-1.jpg` | Thư viện ảnh – showroom | 1600 × 1000 px |
| `anh-2.jpg` | Thư viện ảnh – thi công công trình | 800 × 1000 px |
| `anh-3.jpg` | Thư viện ảnh – đào tạo kỹ thuật | 800 × 800 px |
| `anh-4.jpg` | Thư viện ảnh – ký kết hợp tác | 800 × 800 px |
| `anh-5.jpg` | Thư viện ảnh – hoạt động cộng đồng | 1600 × 800 px |
| `lanh-dao.jpg` | Thông điệp lãnh đạo – chân dung Giám đốc | 900 × 1200 px (dọc) |

Mẹo: nén ảnh dưới 300 KB/ảnh (vd bằng squoosh.app) để trang tải nhanh.
